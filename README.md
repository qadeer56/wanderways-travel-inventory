# WanderWays – Travel Package Inventory System

WanderWays is a Python-based Travel Package Inventory Management System designed to manage travel packages through a simple command-line interface.

## Features

- Add new travel packages
- View all available packages
- Search packages by ID or name
- Update package prices
- Update package stock
- Delete travel packages
- Input validation and error handling
- JSON-based data storage
- Automatic data saving

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Exception Handling

## Project Structure

```text
WanderWays/

```

## How to Run

1. Install Python 3.9 or newer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

## Main Menu

1. Add Package
2. View Packages
3. Search Package
4. Update Package
5. Delete Package
6. Exit

## Data Storage

All travel package records are stored in `packages.json`.

Changes are automatically saved whenever a package is added, updated, or deleted.

# WanderWays – Travel Package Inventory System

WanderWays is a Python-based Travel Package Inventory Management System designed to manage travel packages through a simple command-line interface.

## Features

- Add new travel packages
- View all available packages
- Search packages by ID or name
- Update package prices
- Update package stock
- Delete travel packages
- Input validation and error handling
- JSON-based data storage
- Automatic data saving

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Exception Handling
